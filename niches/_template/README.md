# _template — قالب نيش جديد

انسخ هذا المجلد كما هو. لا تعدّله في مكانه إلا لتحسين القالب نفسه.

```
niche.md          التعريف: الجمهور، النبرة، المحاور، المنافسون، الكلمات المفتاحية
ideas/backlog.md  بنك الأفكار مع التقييم
scripts/          السكريبتات: YYYY-MM-DD-<slug>.md
assets/           روابط ووصف الأصول (لا ملفات ثقيلة)
calendar.md       جدول النشر
analytics.md      نتائج كل منشور والدروس المستفادة
```
