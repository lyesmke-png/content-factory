# .claude/skills — سكيلات المنظومة

| السكيل | متى يُستخدم |
|---|---|
| `trend-research` | لمعرفة ما ينتشر الآن في نيش وتوليد أفكار مقيَّمة. |
| `idea-to-script` | لتحويل فكرة مقبولة من `backlog.md` إلى سكريبت فيديو قصير. |
| `visual-production` | لتوليد صور/فيديو/صوت سكريبت جاهز وتسجيل أصوله. |
| `publish-and-log` | لتجهيز الوصف والهاشتاقات، النشر بعد موافقة المالك، ثم التسجيل. |
| `new-niche` | لإضافة نيش جديد. |
| `weekly-review` | للمراجعة الأسبوعية وتعديل الخطة. |

ترتيب التشغيل الطبيعي:
`trend-research → idea-to-script → visual-production → publish-and-log`، و`weekly-review` أسبوعيًا.
