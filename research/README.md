# research — البحث

- `viral/<niche>/YYYY-MM-DD.md` — تحليل الفيديوهات الأكثر انتشارًا في النيش.
- `viral/<niche>/patterns.md` — أنماط النجاح المتكررة المستخرجة من التحليل (ملف حيّ يُحدَّث).
- `trends/YYYY-MM-DD-<niche>.md` — تقارير الترند والأفكار المرشّحة.

التقارير لا تُحذف ولا تُعاد كتابتها: كل تشغيل يضيف ملفًا بتاريخه، ما يسمح بمقارنة
ما توقّعناه بما نجح فعلًا في `analytics.md`.
