# الفيديوهات المنتَجة — محلّي فقط

مخرجات الإنتاج النهائية (mp4) تُحفظ هنا على الحاسوب **ولا تُرفع إلى Git أبدًا**.

المُلتزم في المستودع هو الخفيف فقط: السكيلات، القواعد، القوالب، السكريبتات،
البحث، الملاحظات، السجلات، والروابط.

لكل فيديو منتَج يُسجَّل سطر في `logs/published.md` (الرابط + التاريخ + النتائج)،
فيبقى الأثر في Git والملف الثقيل خارجه.

البنية: `produced/<niche>/<YYYY-MM-DD-slug>/`
