# content-factory — منظومة صناعة المحتوى متعددة النيشات

مستودع عام لتشغيل مصنع محتوى قصير (فيديو عمودي 9:16، أقل من 60 ثانية) موجّه إلى
**TikTok** و**YouTube Shorts** أولًا، باللغة العربية، مع إمكانية إصدار نسخ إنجليزية لاحقًا.

## النيشات الحالية

| النيش | الوصف |
|---|---|
| [`ai-short-films`](niches/ai-short-films/niche.md) | أفلام قصيرة مصنوعة بالذكاء الاصطناعي، مصمّمة للانتشار السريع: قصص مشوّقة، تحوّلات بصرية، نهايات مفاجئة. |
| [`kids-films`](niches/kids-films/niche.md) | أفلام وقصص قصيرة للأطفال: قيم، مغامرات آمنة، شخصيات ثابتة يتعلّق بها الطفل. |

## خط الإنتاج

```
تحليل الفيديوهات المنتشرة  ->  أنماط النجاح  ->  بحث الترند  ->  بنك الأفكار
      ->  سكريبت  ->  إنتاج بصري/صوتي  ->  مراجعة المالك  ->  نشر  ->  تحليل النتائج
```

كل خطوة لها سكيل مستقل في `.claude/skills/`:

| السكيل | الدور | المخرج الثابت |
|---|---|---|
| `trend-research` | تحليل المنتشر + بحث الترند + تغذية بنك الأفكار | `research/trends/YYYY-MM-DD-<niche>.md` |
| `idea-to-script` | تحويل فكرة إلى سكريبت فيديو قصير | `niches/<niche>/scripts/YYYY-MM-DD-<slug>.md` |
| `visual-production` | توليد الصور/الفيديو/الصوت وتسجيل الأصول | `niches/<niche>/assets/YYYY-MM-DD-<slug>.md` |
| `publish-and-log` | الوصف والهاشتاقات والنشر بعد الموافقة + التسجيل | `calendar.md` + `analytics.md` |
| `new-niche` | إضافة نيش جديد من القالب | `niches/<new-niche>/` |
| `weekly-review` | مراجعة أسبوعية وتعديل الخطة | `niches/<niche>/analytics.md` |

## بنية المستودع

```
shared/brand/       الهوية، الخطوط، الألوان، قواعد الشكل البصري
shared/templates/   قوالب السكريبت والخطة الأسبوعية وتقرير الترند والـ brief
shared/tools/       الأدوات والـ connectors المتاحة + سكربتات مساعدة
research/viral/     تحليل الفيديوهات الأكثر انتشارًا + أنماط النجاح لكل نيش
research/trends/    تقارير الترند المؤرخة
niches/_template/   قالب نيش جديد يُنسخ كما هو
niches/<niche>/     كل نيش: التعريف، الأفكار، السكريبتات، الأصول، الجدول، النتائج
```

## كيف تضيف نيشًا جديدًا

1. شغّل سكيل `new-niche` (أو انسخ يدويًا):
   ```bash
   cp -r niches/_template "niches/<new-niche>"
   ```
2. املأ `niches/<new-niche>/niche.md`: الجمهور، النبرة، المحاور، المنافسون، الكلمات المفتاحية.
3. أنشئ `research/viral/<new-niche>/` وشغّل تحليل المنتشر ثم `trend-research`.
4. أضف صفًّا للنيش في جدول هذا الـ README.

## قواعد لا تُخترق

- المستودع **عام**: لا مفاتيح، لا توكنات، لا بيانات شخصية. `.env.example` فقط.
- لا ملفات ثقيلة (فيديو/صوت/صور خام): روابط ووصف فقط.
- لا نشر ولا إرسال خارجي دون موافقة المالك الصريحة.
- نستلهم أنماط النجاح ولا ننسخ القصص أو الشخصيات أو المشاهد.
- محتوى الأطفال يلتزم بسياسات YouTube "Made for kids" وقواعد TikTok.

التفاصيل الكاملة في [`CLAUDE.md`](CLAUDE.md).
