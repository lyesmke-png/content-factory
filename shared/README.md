# shared — الموارد المشتركة بين كل النيشات

- `brand/` — الهوية البصرية والصوتية العامة: الألوان، الخطوط، قواعد الشكل، نبرة عامة.
- `templates/` — القوالب التي تنسخها السكيلات: سكريبت، خطة أسبوعية، تقرير ترند، brief.
- `tools/` — الأدوات والـ connectors المتاحة في الجلسة + سكربتات مساعدة.

ما يوضع هنا يجب أن يصلح لأكثر من نيش. الخاص بنيش واحد يبقى داخل `niches/<niche>/`.
