### التثبيت — ✅ **تمّ في 2026-11-18**
نُفِّذ من الطرفية (بيئة جلسة Claude تحجب `pip install`):

```bash
python -m pip install edge-tts imageio-ffmpeg
```

`imageio-ffmpeg` يُنزّل نسخة ffmpeg جاهزة بلا صلاحيات مدير ولا تثبيت نظام.

### الحلقة 1 — الصور (Gemini، طبقة مجانية)
1. افتح **aistudio.google.com** → `Get API key` (مجاني).
2. ضع المفتاح في `.env` محليًا: `GEMINI_API_KEY=...` — **لا يدخل المستودع أبدًا**
   (`.env` محجوب في `.gitignore`، والمفتاح مذكور في `.env.example` بقيمة فارغة).
3. الـ prompts جاهزة ومُراجَعة في ملفات `assets/`: انسخ كتل الشخصيات والأسلوب حرفيًا
   في كل صورة — هذا ما يحفظ ثبات «نور» و«سمسم» و«الرجل الرمادي».

**البديل بلا مفتاح:** ولّد الصور يدويًا من أي واجهة ويب مجانية، وانزلها في مجلد
محلي خارج المستودع، ثم سجّل الوصف فقط في `assets/` (المستودع يمنع الصور).

### الحلقة 2 — الصوت العربي (بلا مفتاح، بلا حد)
```bash
# أصوات عربية متاحة
python -m edge_tts --list-voices | grep ar-

# مثال: راوية مصرية هادئة
python -m edge_tts --voice ar-EG-SalmaNeural --rate=-10% \
  --text "سمسم كسر كوب نور. ولم يكن يريد ذلك." --write-media line01.mp3
```
- `ar-EG-SalmaNeural` / `ar-SA-ZariyahNeural`: مرشّحتان لراوية نيش الأطفال.
- `ar-SA-HamedNeural` / `ar-EG-ShakirNeural`: مرشّحان لصوت «الرجل الرمادي».
- `--rate=-10%` يبطّئ النطق — مطلوب لجمهور 4–8 سنوات.
- **ثبّت الصوت المختار واستخدمه في كل الفيديوهات** (التعرّف الصوتي جزء من الهوية).

> ⚠ **لا تمرّر نصًا عربيًا عبر `--text` في PowerShell**: الترميز يتلف فيصل النص
> إلى المحرّك كـ `????`. استخدم `--file line.txt` وملفًا بترميز UTF-8.

**مُتحقَّق منه 2026-11-18:** `ar-EG-SalmaNeural --rate=-10%` أنتج 11.45 ثانية
سرد عربي سليم بحجم 68 KB، بصفر تكلفة وبلا مفتاح.

### الحلقة 3 — الحركة والتجميع
`build-video.py` في نفس المجلد يبني فيديو 9:16 كامل من الصور الثابتة:
حركة Ken Burns (تكبير/تحريك بطيء) لكل لقطة، ثم وصلها، ثم دمج التعليق والموسيقى.
```bash
python shared/tools/build-video.py --shots ./shots --audio ./narration.mp3 \
  --music ./music.mp3 --out ./out.mp4 --seconds-per-shot 5
```
الصور الثابتة + حركة الكاميرا تعطي فيديو حقيقي بلا أي توليد فيديو مدفوع.
**هذا هو الاستبدال الأساسي لـ 52.5 كريدت للفيديو الواحد.**

**مُتحقَّق منه طرفًا لطرف 2026-11-18:** 4 صور + سرد ⇒ `h264 1080x1920 @30fps`
مع `aac` بطول 12.00 ثانية بالضبط. حركة الكاميرا تتبدّل بين اللقطات (تقريب/تبعيد
وانزلاق في أربعة اتجاهات) فلا تبدو اللقطات متطابقة الإيقاع.
الصوت مُبطَّن بـ `apad` ⇒ **سرد أقصر من اللقطات لا يقتطع الصورة** (عيب رُصد وأُصلح
في الاختبار الأول: كان الناتج 11.45 ث بدل 12).

### الحلقة 4 — النص العربي على الشاشة

الحلقة 3 يُستورد مباشرة. وهذا أيضًا مكان إضافة الترجمة الإلزامية للمشاهدة الصامتة.

## ما يتغيّر في السكريبتات
- لا «لقطة فيديو مُولَّدة»: كل لقطة **صورة ثابتة + حركة كاميرا بطيئة**.
- هذا **يناسب نيش الأطفال تمامًا** (`#pattern-slow-cut`: لقطة كل 3–5 ثوانٍ).
- وفي `ai-short-films` يفرض قيدًا حقيقيًا: اللقطات التي تعتمد على حركة داخل الكادر
  (مثل الانعكاس المتأخّر في `the-mirror`) تحتاج إعادة تصميم كصورتين متجاورتين
  أو قطع سريع بين صورتين، لا كحركة مستمرة.
- `the-elevator` **قابل للتنفيذ كما هو**: كل لقطاته ثابتة أصلًا (لوحة أرقام، وجه، باب).
