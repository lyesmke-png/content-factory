# قرار الأدوات — 2026-11-21

المالك فوّض القرار، وحدّد الإطار: **نعمل بالحاسوب كما هو**، وترقية العتاد
تأتي **بعد** انتشار حقيقي ودخل فعليّ من المشروع. هذا هو القرار وأسبابه.

---

## القياس الذي غيّر كل شيء

قِستُ أبعاد الصورة داخل أقوى مرجع لدينا (8.4 مليون مشاهدة) بـ`cropdetect`:

```
crop=360:322:0:130   في إطار 360×640
```

**الصورة تشغل 50% من ارتفاع الإطار فقط**، ونسبتها **1.12:1** (شبه مربّعة)،
والباقي شريط أسود يحمل العنوان ورقم الجزء.

مقيسًا على 1080×1920، الصورة المطلوبة = **1080×966**.

### لماذا هذا هو المفتاح
كنّا نظنّ أننا نحتاج توليد 1080×1920 كاملًا. الحقيقة أننا نحتاج **ربع ذلك تقريبًا**.
توليد 640×576 ثم تكبيره 1.69× يملأ الشريط تمامًا.

**وهذا يُدخل بطاقة 4GB إلى الملعب.** الحائط الذي وصفته أمس كان مبنيًّا على
افتراض خاطئ عن الدقّة المطلوبة.

## المنظومة المعتمدة

| المرحلة | الأداة | الرخصة | لماذا |
|---|---|---|---|
| **الفيديو** | **Wan 2.2 TI2V 1.3B** عبر ComfyUI | Apache-2.0 ✅ | الوحيد الذي يعمل في 4–6GB، وبلا علامة مائية وبحقوق تجارية |
| **التكبير** | **Real-ESRGAN** (`realesr-animevideov3`) | BSD-3 ✅ | 1.7× كافٍ لملء الشريط؛ النموذج المخصّص للرسوم أنسب من العام |
| **الصوت** | `edge-tts` | مجاني بلا مفتاح | مُشتغِل ومُختبَر |
| **التجميع** | `ffmpeg` | LGPL ✅ | مُشتغِل ومُختبَر |
| **النصّ على الشاشة** | `ffmpeg drawtext` | — | شريط العنوان + ترجمة عربية |

**لا خدمة مستضافة في المسار.** كلها إمّا تضع علامة مائية أو تمنع الاستعمال
التجاري (موثّق في `TOOLING_2026-11-21.md`). ما نُنتجه ملكنا بالكامل.

## الصيغة المعتمدة لكل فيديو

```
┌─────────────────┐ 1080×1920
│  شريط العنوان   │  ← اسم المسلسل + «المشهد ٣»  (ثابت، كل إطار)
├─────────────────┤
│                 │
│   الصورة        │  1080×966  ← مولَّدة 640×576 ثم ×1.7
│                 │
├─────────────────┤
│  نصّ الحوار     │  ← ترجمة عربية مشكَّلة، تملأ الفراغ السفلي
└─────────────────┘
```

ثلاث مكاسب في قرار واحد:
1. **الدقّة المطلوبة تنخفض إلى الربع** — فيعمل العتاد الحالي.
2. **الشريط العلوي يحمل الوعد بالتسلسل** (`#title-bar-in-frame`).
3. **الفراغ السفلي يحمل النصّ** — وهي الثغرة التي وجدناها في مراجع
   الأطفال الخمسة: لا أحد منهم يضع نصًّا، فيخسرون كل مشاهد بصوت مكتوم.

## قواعد تصميم تفرضها الأداة

مستمدّة من `#designed-for-consistency` (درس POOF):

- **لا وجوه بشرية محدّدة.** النموذج يفشل في إعادة وجه بعينه، وينجح في
  إعادة «مخلوق فروي برتقالي» أو «معطف رمادي».
- كل شخصية = **سمة واحدة قويّة**: لون، شكل، صورة ظلّية.
- **تدرّج لوني واحد للمسلسل كلّه** (`#one-grade-one-series`) — يوحّد
  ويخفي القطع، وهو مجاني: يُطبَّق في `ffmpeg` لا في التوليد.
- **لقطات قصيرة مستقلّة**، لا استمرارية حركة معقّدة بين اللقطات.
- نيش الأطفال: قطعة كل ~5 ثوانٍ · نيش الذكاء الاصطناعي: كل ~3 ثوانٍ.

## ما يحتاجه التشغيل (أوامر للمالك)

`pip` محجوب في جلستي، فهذه تُنفَّذ من الطرفية:

```powershell
# 1. PyTorch بنواة CUDA مناسبة لبطاقة 1050 Ti
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126

# 2. ComfyUI
git clone https://github.com/comfyanonymous/ComfyUI "D:\AI\ComfyUI"
python -m pip install -r "D:\AI\ComfyUI\requirements.txt"

# 3. المكبّر
python -m pip install realesrgan basicsr
```

ثم تُنزَّل أوزان **Wan 2.2 TI2V 1.3B** إلى مجلد نماذج ComfyUI.

## التوقّع الصادق
- **زمن التوليد:** دقائق لكل مقطع 5 ثوانٍ على 1050 Ti. فيديو من 8 لقطات
  = ساعة إلى ساعتين. مقبول لفيديو كل يومين، لا لعشرة في اليوم.
- **الجودة:** أدنى من Veo وKling. لكنها **قابلة للنشر وبلا علامة مائية
  وملكنا**، وهذا ما لا تعطيه الخدمات المجانية.
- **إن خاب الظنّ عمليًّا:** نرجع إلى الخدمات المجانية **للتجريب فقط**،
  ونعيد فتح ملف الترقية عند أول دخل — وهو ما حدّده المالك أصلًا.
