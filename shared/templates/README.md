# templates — القوالب

| الملف | يستخدمه | المخرج |
|---|---|---|
| `script-template.md` | `idea-to-script` | `niches/<niche>/scripts/YYYY-MM-DD-<slug>.md` |
| `trend-report-template.md` | `trend-research` | `research/trends/YYYY-MM-DD-<niche>.md` |
| `viral-analysis-template.md` | `trend-research` (المرحلة الأولى) | `research/viral/<niche>/YYYY-MM-DD.md` |
| `weekly-plan-template.md` | `weekly-review` / `publish-and-log` | قسم في `niches/<niche>/calendar.md` |
| `brief-template.md` | أي سكيل يحتاج تكليف إنتاج | مؤقت، يُرفق مع السكريبت |
| `assets-template.md` | `visual-production` | `niches/<niche>/assets/YYYY-MM-DD-<slug>.md` |

القوالب تُنسخ ولا تُعدَّل في مكانها. أي حقل غير معروف يُكتب `غير محدد` ولا يُحذف.
